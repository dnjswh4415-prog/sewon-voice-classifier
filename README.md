# SEWON Voice Classifier

SEWON Voice Classifier is a Next.js-based web application project for voice-classification related features and data handling.

## Tech Stack

- Next.js 15
- React 19
- TypeScript
- Prisma
- JWT / bcryptjs
- Anthropic SDK
- Google APIs
- Zod

## Getting Started

```bash
npm install
npm run dev
```

Then open the local development server in your browser.

## Available Scripts

```bash
npm run dev
npm run build
npm run start
npm run lint
```
